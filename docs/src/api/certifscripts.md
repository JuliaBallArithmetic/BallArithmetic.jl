# API - CertifScripts

The drivers that cover a contour: the adaptive arc refinement, the serial, distributed and
refined modes, and the snapshots a long cover is resumed from. The quantity they bound at each
sample point, and the bounds that are prepared once and evaluated cheaply afterwards, are on the
[Pseudospectra](@ref "API - Pseudospectra") page; [Pseudospectra Certification](@ref) reads the
modes side by side and says which to use when.
