Triangular Systems

BallArithmetic.backward_substitution — Function
backward_substitution(A::BallMatrix, v::BallVector)
backward_substitution(A::BallMatrix, B::BallMatrix)

Enclose the solution of A x = v, or of A X = B column by column, for an upper triangular A: the rows are eliminated from the last to the first, each step a ball subtraction and one ball division by the diagonal entry, so the result encloses the solution of every real or complex system whose matrix and right hand side lie in A and in v.

Both the midpoints and the radii of A are required to be upper triangular, since a nonzero radius below the diagonal would describe a matrix that is not; an ArgumentError is raised otherwise, and a DimensionMismatch when A is not square. A diagonal ball containing zero raises an ArgumentError from the division rather than returning an unbounded enclosure, so a matrix whose enclosure admits a singular member is rejected and not reported as solved.

source
BallArithmetic.forward_substitution — Function
forward_substitution(A::BallMatrix, v::BallVector)
forward_substitution(A::BallMatrix, B::BallMatrix)

The same as backward_substitution for a lower triangular A, eliminating the rows from the first to the last; midpoints and radii are both required to be lower triangular.

Cholesky Factorization

BallArithmetic.verified_cholesky — Function
verified_cholesky([T = BigFloat,] A::AbstractMatrix; precision_bits = 256)

An inclusion of the Cholesky factor of A, by Section 4 of Rump and Ogita (2024); the method is described at _rumpogita2024_cholesky. Returns a VerifiedCholeskyResult: when certified is true, A is proved positive definite and A = G*G with G upper triangular with positive diagonal, in the ball matrix returned. Positive definiteness is a conclusion and not an assumption.

When A is not Hermitian a warning is issued (above a rounding-level threshold) and the statement is for its Hermitian part (A + A*)/2, enclosed in ball arithmetic.

Arguments

  • T: the arithmetic of the enclosure, BigFloat (the default) or Float64, as a leading argument. In BigFloat the computation runs at precision_bits and the factor is enclosed to about that precision. Float64 with a BigFloat input raises.
  • precision_bits: the BigFloat precision. A BigFloat input with more digits is rounded to it and the rounding is enclosed.

Example

B = randn(100, 100); A = B' * B + I
r = verified_cholesky(Float64, A)
r.certified      # A is positive definite and its Cholesky factor lies in r.G

Reference

S. M. Rump and T. Ogita, Verified Error Bounds for Matrix Decompositions, SIAM J. Matrix Anal. Appl. 45(4) (2024), 2155-2183, doi 10.1137/24M165096X, Section 4.

BallArithmetic.interval_gaussian_elimination — Function
interval_gaussian_elimination(A::BallMatrix, b::BallVector; pivoting = :partial)
    -> GaussianEliminationResult

Gaussian elimination and backward substitution in ball arithmetic for the square real interval system A x = b: Algorithms 5.9 and 5.10 of Horáček (2019).

Elimination, for k = 1, …, n − 1: a row j ≥ k whose entry in column k does not contain zero is brought to position k; for every row j > k the entry a_jk is set to zero and

a_j,k+1:n := a_j,k+1:n − (a_jk / a_kk) a_k,k+1:n,        b_j := b_j − (a_jk / a_kk) b_k.

If no such row exists the elimination stops, and the result is not certified. Backward substitution: x_i := (b_i − Σ_{j>i} a_ij x_j) / a_ii for i = n, …, 1.

Why the result is an enclosure: for a fixed Â in A and b̂ in b, Gaussian elimination on them with the same order of the rows evaluates the same formulae on numbers contained in the balls, and every operation on balls contains the result of the operation on their points; a pivot that does not contain zero is not zero for Â. So Â is nonsingular, its solution is in solution, and its factors are in L and U.

pivoting = :partial chooses, among the rows whose entry does not contain zero, the one whose entry is farthest from zero (the largest lower bound of its absolute value). Step 2 of Algorithm 5.9 asks only for a row whose entry does not contain zero and leaves the choice free; the thesis then says that it selects "a pivot with the smallest mignitude". pivoting = :none keeps the rows in their order and stops at the first pivot that contains zero.

The enclosure may be much wider than the hull of the solution set: the radii grow with the number of operations, as Example 5.11 of the thesis shows. The thesis recommends preconditioning by the inverse of the midpoint (compute_preconditioner).

Reference

J. Horáček, "Interval linear and nonlinear systems", PhD thesis, Charles University, Prague, 2019, Section 5.6.1.

BallArithmetic.interval_initial_enclosure — Function

A box that contains the solution set of the square interval system A x = b, by Section 5.7.1 of Horáček (2019), with C a real matrix (any; the default is the floating-point inverse of the midpoint):

  • method = :proposition, Proposition 5.14: if ⟨CA⟩u ≥ v > 0 for some u ≥ 0, then Σ ⊆ ‖Cb‖_v [−u, u], with ‖x‖_v = max_i |x_i|/v_i. u is an approximate solution of ⟨CA⟩u = e and v a lower bound of ⟨CA⟩u, as the thesis suggests.

BallArithmetic.interval_jacobi — Function
interval_jacobi(A::BallMatrix, b::BallVector; x0 = nothing, preconditioner = nothing,
    max_iterations = 20, tol = nothing) -> IterativeResult

Algorithm 5.15 of Horáček (2019), the Jacobi method for a real square interval system A x = b: from a box x⁽⁰⁾ containing the solution set,

y_i⁽ᵏ⁺¹⁾ = (b_i − Σ_{j≠i} a_ij x_j⁽ᵏ⁾)/a_ii,        x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ ∩ y⁽ᵏ⁺¹⁾,

BallArithmetic.hbr_method — Function
hbr_method(A::BallMatrix, b::BallVector; preconditioner = nothing) -> HBRResult

Theorem 5.12 of Horáček (2019). Let A x = b be a real square interval system with A an H-matrix, ⟨A⟩ its comparison matrix,

u = ⟨A⟩⁻¹ mag(b),    d_i = (⟨A⟩⁻¹)_ii,    α_i = ⟨A⟩_ii − 1/d_i,    β_i = u_i/d_i − mag(b_i).

Then the solution set is contained in the box with components

x_i = (b_i + [−β_i, β_i]) / (A_ii + [−α_i, α_i]).

When the midpoint of A is diagonal the box is the hull (the thesis, after the theorem).

The theorem is applied to the preconditioned system (CA) x = Cb, formed in ball arithmetic, whose solution set contains that of A x = b (Section 5.4). preconditioner = nothing takes C the floating-point inverse of the midpoint; a real matrix is used as given; hbr_method_simple applies the theorem to A x = b itself.

How it is verified: that the matrix is an H-matrix by is_H_matrix; ⟨A⟩⁻¹ is enclosed by verifylss, as the thesis suggests with the ε-inflation method; α_i and β_i are replaced by upper bounds, which enlarges the box, since the quotient grows with both. certified is false where one of these steps fails.

BallArithmetic.interval_shaving — Function
interval_shaving(A::BallMatrix, b::BallVector, x0::BallVector; passes = 1,
    improvements = 3, min_improvement = 1e-6, lp_solver = nothing) -> ShavingResult

The shaving method of Section 5.9 of Horáček (2019) for a real square interval system A x = b: slices of the box x0 that contain no point of the solution set are cut off. With x0 an enclosure of the solution set, so is the result.

For the variable i and the upper end, the slice of width α is the box with x_i restricted to [x̄_i − α, x̄_i] (5.8), and similarly at the lower end. For each of the 2n slices:

  1. A certificate for the midpoint system (Section 5.9.1). By Lemma 5.21, A x = b, x ∈ x has no solution exactly when

    Aᵀw + y − z = 0,    bᵀw + x̄ᵀy − x̲ᵀz = −1,    y, z ≥ 0                        (5.9)

    is solvable. The linear programme min b_cᵀw + x̄ᵀy − x̲ᵀz subject to A_cᵀw + y − z = 0, −e ≤ w ≤ e, y, z ≥ 0 is solved for the slice of width zero. If its value is not negative the slice is kept.

  2. A square interval system. The entries of y and z that vanish at the optimum are fixed to zero; the remaining system (5.12) is completed to a square one, C v = d, C ∈ C, with an orthonormal basis of the null space of its midpoint, the right-hand sides chosen so that the normalised optimum solves it (5.13). Its solution set is enclosed by verifylss. If the components u of the enclosure that come from y and z are nonnegative, (5.9) is solvable for every A ∈ A, b ∈ b, and the slice contains no point of the solution set.

  3. The width (Section 5.9.2). The width α enters one coefficient, C + α e_p e_qᵀ, and by Lemma 5.22 the solution becomes v − α v_q/(1 + α C⁻¹_qp) · C⁻¹_*p. With c an enclosure of C⁻¹_*p, the solution set of C u = e_p, the largest α allowed is given by α < −1/c̲_q when c̲_q < 0 (5.15) and, for every component k of u other than q, α ≤ u̲_k / (sup(u_q c_k) − u̲_k c̲_q) when the denominator is positive (5.16), all rounded downwards.

  4. Iterative improvement (Section 5.9.3), improvements times: the coefficient is moved by the width found, the system enclosed again, c updated by c/(1 + α c_q), with its q-th component computed as 1/(α + 1/c_q), and a further width added.

passes is the number of sweeps over the variables; a slice narrower than min_improvement times the width of its variable is not cut.

lp_solver(c, Aeq, beq, lb, ub) must return a minimiser of c'v subject to Aeq v = beq, lb ≤ v ≤ ub, or nothing. It is a heuristic: whatever it returns, a slice is cut only after step 2 has verified the certificate. nothing uses JuMP with HiGHS, which must then be loaded (using JuMP, HiGHS); see _shaving_lp.

Reference

J. Horáček, Interval linear and nonlinear systems, doctoral thesis, Charles University, Department of Applied Mathematics, Prague, 2019 ([26]), Section 5.9, Lemma 5.21 and Lemma 5.22.

BallArithmetic.sherman_morrison_inverse_update — Function
sherman_morrison_inverse_update(A_inv::Matrix{T}, u::Vector{T}, v::Vector{T}) where {T}

Compute (A + uv^T)^(-1) using Sherman-Morrison formula.

Sherman-Morrison Formula

(A + uv^T)^(-1) = A^(-1) - (A^(-1)uv^T A^(-1)) / (1 + v^T A^(-1)u)

This allows O(n²) update of inverse for rank-1 perturbation instead of O(n³) recomputation.

Arguments

  • A_inv: Inverse of base matrix A (n×n)
  • u: First vector of rank-1 update (n)
  • v: Second vector of rank-1 update (n)

Returns

(A + uv^T)^(-1)

Example

A = [3.0 1.0; 1.0 2.0]
A_inv = inv(A)
u = [1.0, 0.0]
v = [0.0, 1.0]

# Efficiently compute inv(A + u*v')
A_updated_inv = sherman_morrison_inverse_update(A_inv, u, v)

Notes

  • O(n²) complexity vs O(n³) for full inverse
  • Numerically stable if |1 + v^T A^(-1)u| is not too small
  • A floating-point formula: the result is an approximation, with no error bound

Compute preconditioner C ≈ A^(-1) for interval matrix A.

Methods

  • :midpoint: Direct inverse of A_c (default, simplest)
  • :lu: LU factorization of A_c (more stable)
  • :ldlt: LDLT factorization of A_c (for symmetric A)
  • :identity: Identity matrix (no preconditioning)

Arguments

  • A: Interval matrix to precondition
  • method: Preconditioning strategy
  • check_conditioning: Compute and warn about condition number

Returns

PreconditionerResult with approximate inverse and diagnostic info.

A = BallMatrix([4.0 1.0; 1.0 3.0], fill(0.1, 2, 2))

  • Identity: O(1), use for well-conditioned or diagonally dominant matrices

BallArithmetic.select_subsquares — Function
select_subsquares(m, n; overlap = round(Int, n/3), rng = nothing) -> Vector{Vector{Int}}

Algorithm 6.14 of Horáček (2019): row index sets of square subsystems covering the m equations of an m × n system. The first is chosen at random; each following one takes overlap equations already covered and n − overlap not yet covered; the last takes the remaining ones and completes with covered ones. BallArithmetic.subsquares_method — Function
subsquares_method(A::BallMatrix, b::BallVector; selection = :covering, k = 10,
    overlap = round(Int, n/3), solver = :hbr, rng = nothing) -> OverdeterminedResult

Algorithm 6.12 of Horáček (2019), the simple subsquares algorithm, for a real overdetermined interval system. The solution set lies in the solution set of every square subsystem (Proposition 6.5), so:

  1. select square subsystems: selection = :random, k random ones, as in the algorithm; :covering, those of select_subsquares (Algorithm 6.14); :all, all binomial(m, n);
  2. enclose the solution set of each by a method for square systems, solver = :hbr (hbr_method), :verifylss or :gaussian_elimination;
  3. return the intersection of the enclosures;
  4. if the intersection is empty, the system has no solution: unsolvable = true.

A subsquare for which the solver gives no enclosure is skipped. certified is false when none gives one.

BallArithmetic.multi_jacobi_method — Function
multi_jacobi_method(A::BallMatrix, b::BallVector; x0 = nothing, overlap = round(Int, n/3),
    max_iterations = 20, tol = nothing, rng = nothing) -> OverdeterminedResult

Section 6.8.3 of Horáček (2019), the multi-Jacobi method: subsquares are selected by Algorithm 6.14 (select_subsquares); then, instead of solving each, one iteration of the Jacobi method (Algorithm 5.15) is applied to every subsquare from the current global box, the global box is intersected with all the results, and this is repeated until the stopping criterion of Section 5.7.2 or max_iterations.

  • x0: a box containing the solution set. nothing takes the HBR enclosure of a subsquare, as in Example 6.15 of the thesis (the first selected subsquare for which it exists).
  • Each subsquare is preconditioned by the floating-point inverse of its midpoint, the products formed in ball arithmetic. The thesis does not say how the diagonal of a subsquare is kept free of zero; this is the preconditioning of Section 5.4 applied to each subsquare.

An empty intersection proves that the system has no solution (unsolvable = true). certified is false when no initial box is found.

BallArithmetic.interval_least_squares — Function
interval_least_squares(A::BallMatrix, b::BallVector; method = :supersquare,
    solver = :verifylss) -> OverdeterminedResult

Section 6.2 of Horáček (2019): an enclosure of the set of least squares solutions (Definition 6.3)

Σ_lsq = {x : AᵀA x = Aᵀb for some A ∈ A, b ∈ b},

whose hull contains that of the solution set of A x = b; the result is nonempty also when the system has no solution.

An entrywise bound ε of the error of an approximate solution x̃ of a real linear system: |Â⁻¹ b̂ − x̃| ≤ ε for every matrix Â in A and every vector b̂ in b, together with the proof that every such Â is nonsingular. Returns a VerifiedLinearSystemResult; certified is false, and the bound infinite, when the hypothesis could not be proved.

The hypothesis, common to all four bounds: with R an approximate inverse and C a ball matrix containing R Â for every Â in A, there is a vector v > 0 with u := ⟨C⟩ v > 0, where ⟨C⟩ is the comparison matrix (see comparison_matrix). Then C is an H-matrix, Â and R are nonsingular, and |(R Â)⁻¹| ≤ ⟨C⟩⁻¹ (Theorems 2.1 and 2.3, Remark 1). Write ⟨C⟩ = D − E with D the diagonal part, G := E D⁻¹, and c for an upper bound of |R (b̂ − Â x̃)|.

method selects the bound:

  • :theorem_3_1 (Rump): ε = (D⁻¹ + v wᵀ) c with w_k := max_i G_ik / u_i, equation (3);
  • :theorem_3_2 (Minamihata, Sekine, Ogita, Rump and Oishi 2015): ε = (D⁻¹ + v wᵀ) (I − Σ_{k=1}^m (Δ^{2k−1} − Δ^{2k})) c with Δ := u wᵀ − G, equation (4);
  • :theorem_3_3 (the default): ε = min_{1 ≤ k ≤ m} ε^(k), ε^(k) := D⁻¹ (c^(0) + … + c^(k−1)) + max_i (c^(k)_i / u_i) v, with c^(0) := c and c^(k) := G c^(k−1), equations (5) and (6);
  • :corollary_3_2: ε = D⁻¹ r + α v with r := ⟨mid C⟩ |ỹ| + |mid(C) ỹ − R (b̂ − Â x̃)|, α := max_i (G r)_i / u_i and ỹ an approximate solution of mid(C) y = R (b − A x̃), equation (17).

m is the number of terms in Theorems 3.2 and 3.3. R defaults to the floating-point inverse of mid(A) and x_approx to R mid(b).

How it is computed. C and the residual R (b − A x̃) are products and sums of balls, so they contain what they should for every point of A and b; the residual is formed in working precision. v is the floating-point solution of ⟨C⟩ v = (1, …, 1)ᵀ, the first of the two choices named in Section 3 of the paper, and u is then enclosed, its lower end being the one that has to be positive. The bounds of Theorems 3.1, 3.3 and of Corollary 3.2 are sums and products of nonnegative numbers, rounded upwards, with u replaced by its lower end where it divides. The bound of Theorem 3.2 has terms of both signs and is evaluated in balls, w being any vector with G ≤ u wᵀ, which is all its proof uses; the upper end is returned.

What is not reproduced. The paper distinguishes two enclosures of R A, Method (a) from two products with directed rounding and Method (b) from one product and the a priori bound 2 n u |R| |A|, and proposes Corollary 3.2 for the second. Here there is one enclosure, the ball product of the package, and each of the four bounds is applied to it (Remark 5 of the paper allows Corollary 3.2 on any enclosure); the comparison of costs between the two methods does not carry over.

BallArithmetic.krawczyk_linear_system — Function
krawczyk_linear_system(A::BallMatrix, b::BallVector; max_iterations = 20) -> KrawczykResult

A verified enclosure of the solution of A x = b, for every matrix of the ball A and every vector of the ball b: verifylss, which is Algorithm 10.7 of Rump (2010), with its result in the fields of a KrawczykResult.

With R a floating-point inverse of the midpoint of A and x̃ = R mid(b), the algorithm iterates X ← Z + C·Y, Z ∋ R(b − Ax̃), C ∋ I − RA, Y an inflation of X, all in ball arithmetic, and stops when X is in the interior of Y; then A and R are nonsingular and the solution is in x̃ + X (Theorem 10.8 there). The preconditioner and the approximate solution are those of the algorithm; the keywords R, x_approx and expansion_factor of earlier versions are gone with the code that used them, which formed I − RA in floating point and left the residual out of the inclusion test.

BallArithmetic.sylvester_miyajima_enclosure — Function
sylvester_miyajima_enclosure(A, B, C, X̃)

An entrywise enclosure of the solution X* of A X + X B = C, as a BallMatrix with midpoint X̃ (an approximate solution, in floating point) and radius X^ε with |X̃ − X*| ≤ X^ε. A (m×m), B (n×n) and C may be matrices or BallMatrix; with balls, the enclosure holds for the solution of every equation with data in them.

Theorems 1 and 2 of

S. Miyajima, Fast enclosure for solutions of Sylvester equations, Linear Algebra Appl. 439 (2013), 856–878, doi:10.1016/j.laa.2012.07.001 ([3]),

Section 2.1 (spectral decomposition). The block-diagonalisation variant of Section 2.2 (Theorems 3 and 4), the accelerations of Section 3 and the refinement of Section 4 are not implemented.

The statement

Let Ṽ_A, W_A (m×m), Ṽ_B, W_B (n×n) be any matrices and D̃_A, D̃_B diagonal; in practice A ≈ Ṽ_A D̃_A Ṽ_A⁻¹, Bᵀ ≈ Ṽ_B D̃_B Ṽ_B⁻¹, W_A ≈ Ṽ_A⁻¹, W_B ≈ Ṽ_B⁻¹, all computed in floating point. E is the m×n matrix of ones, ./ and |·| are entrywise, ‖·‖_∞ is the maximum row sum and ‖·‖_M the largest entry in modulus.

R_A = W_A(Ṽ_A D̃_A − A Ṽ_A),     R_B = W_B(Ṽ_B D̃_B − Bᵀ Ṽ_B),
S_A = I − W_A Ṽ_A,              S_B = I − W_B Ṽ_B,
T_A = |R_A| + ‖R_A‖_∞/(1 − ‖S_A‖_∞) |S_A|,     T_B likewise,
T = T_A E + E T_Bᵀ,     D̃ = D̃_A E + E D̃_B,     T_D = T ./ |D̃|.

Theorem 1. If ‖S_A‖_∞ < 1, ‖S_B‖_∞ < 1, D̃ has no zero entry and ‖T_D‖_M < 1, the equation has a unique solution X*.

With R = A X̃ + X̃ B − C, R_W = W_A R W_Bᵀ, and ρ_i(M), κ_j(M) the largest entry in modulus of row i and of column j,

R_W⁽¹⁾ = |R_W| + 1/(1 − ‖S_B‖_∞) · diag(ρ(R_W)) E |S_B|ᵀ,
R_V⁽¹⁾ = R_W⁽¹⁾ + 1/(1 − ‖S_A‖_∞) · |S_A| E diag(κ(R_W⁽¹⁾)),
R_W⁽²⁾ = |R_W| + 1/(1 − ‖S_A‖_∞) · |S_A| E diag(κ(R_W)),
R_V⁽²⁾ = R_W⁽²⁾ + 1/(1 − ‖S_B‖_∞) · diag(ρ(R_W⁽²⁾)) E |S_B|ᵀ,
R_V = min(R_V⁽¹⁾, R_V⁽²⁾),     R_D = R_V ./ |D̃|,
U = R_D + ‖R_D‖_M/(1 − ‖T_D‖_M) · T_D.

Theorem 2. Under the hypotheses of Theorem 1, |X̃ − X*| ≤ X^ε := |Ṽ_A| U |Ṽ_B|ᵀ.

R_V bounds |Ṽ_A⁻¹ R Ṽ_B⁻ᵀ|, the residual in the exact inverse frames, from R_W, the one in the computed W_A, W_B.

How it is evaluated

The products of matrices are ball products, of which the entrywise upper bound is taken. The products with E are row sums ((M E)_ij is the sum of row i of M), accumulated rounded up; |D̃_ij| is bounded from below; every other operation is rounded up. Throws ArgumentError when a hypothesis of Theorem 1 is not proved.

  • CouplingOffDirect: A_z⁻¹RD_z⁻¹ = W + A_z⁻¹(R − A_zWD_z)D_z⁻¹ for an approximate W, so the term is at most ‖W‖₂ + ‖A_z⁻¹‖₂‖R − A_zWD_z‖₂‖D_z⁻¹‖₂

In the last two the residual is computed in ball arithmetic; when the approximate solve does not return finite numbers the first bound is used.

BallArithmetic.is_regular_sufficient_condition — Function
is_regular_sufficient_condition(A::BallMatrix; condition = 1) -> RegularityResult

Theorem 11.12 of Horáček (2019): the interval matrix A is regular if

  1. λ_max(A_Δᵀ A_Δ) < λ_min(A_cᵀ A_c) (condition = 1), or
  2. A_cᵀ A_c − ‖A_Δᵀ A_Δ‖ I is positive definite for some consistent matrix norm (condition = 2, evaluated with the ∞-norm).

Both are evaluated through singular values: λ_min(A_cᵀ A_c) = σ_min(A_c)² ≥ 1/b² with b ≥ ‖A_c⁻¹‖₂ from svd_bound_L2_opnorm_inverse, and λ_max(A_Δᵀ A_Δ) ≤ ν² with ν ≥ ‖A_Δ‖₂ from upper_bound_L2_opnorm, or, for the second condition, an upper bound of ‖A_Δᵀ A_Δ‖_∞ computed in ball arithmetic. The certificate is a lower bound of the difference of the two sides, and regularity is proved when it is positive.

The thesis states the theorem for real interval matrices. For a complex ball matrix the first condition still implies regularity, since σ_min(A_c + E) ≥ σ_min(A_c) − ‖E‖₂ and ‖E‖₂ ≤ ‖A_Δ‖₂ for |E| ≤ A_Δ; the second is weaker than the first.

Reference

J. Horáček, Interval linear and nonlinear systems, doctoral thesis, Charles University, Department of Applied Mathematics, Prague, 2019 ([26]), Theorem 11.12.

is_regular_gershgorin(A::BallMatrix) -> RegularityResult

Regularity from the Geršgorin discs of the rows or of the columns: if zero lies outside every row disc of every matrix of the ball, or outside every column disc, the matrix is regular. BallArithmetic.is_regular_spectral_radius — Function
is_regular_spectral_radius(A::BallMatrix; R = nothing) -> RegularityResult

Theorem 4.2 of Horáček (2019): a square interval matrix A is regular if for some real matrix R

ϱ(|I − R A_c| + |R| A_Δ) < 1.

R = nothing takes the floating-point inverse of the midpoint, which need not be exact: the theorem holds for any R. The matrix |I − R A_c| + |R| A_Δ is bounded above entrywise in ball arithmetic and its spectral radius by collatz_upper_bound; the certificate is that bound, and regularity is proved when it is below one. With R = A_c⁻¹ the condition is ϱ(|A_c⁻¹| A_Δ) < 1, strong regularity (Theorem 4.33 of the thesis). The condition is sufficient only: certified = false does not say that the ball contains a singular matrix.

Reference

J. Horáček, Interval linear and nonlinear systems, doctoral thesis, Charles University, Department of Applied Mathematics, Prague, 2019 ([26]), Theorem 4.2 and Theorem 4.33.

BallArithmetic.is_singular_sufficient_condition — Function
is_singular_sufficient_condition(A::BallMatrix; conditions = 1:4) -> Bool

Theorem 11.13 of Horáček (2019): a real interval matrix A is singular, that is, it contains a singular matrix, if at least one of the following holds:

  1. λ_max(A_cᵀ A_c) ≤ λ_min(A_Δᵀ A_Δ);
  2. max_j (|A_c⁻¹| A_Δ)_jj ≥ 1;
  3. (A_Δ − |A_c|)⁻¹ ≥ 0;
  4. A_Δᵀ A_Δ − A_cᵀ A_c is positive semidefinite.

Returns true when one of the conditions listed in conditions is proved, false otherwise, which does not mean that the matrix is regular. How each is evaluated:

  1. as ‖A_c‖₂ ‖A_Δ⁻¹‖₂ ≤ 1 with upper bounds of the two norms;
  2. with an enclosure of A_c⁻¹ by verifylss, the moduli of its entries bounded from below and the products with A_Δ rounded down;
  3. with an enclosure of the inverse of the ball matrix A_Δ − |A_c| (the subtraction is rounded) by verifylss, all of whose lower ends must be nonnegative; an inverse with an entry equal to zero is therefore not recognised;
  4. with enclosures of the eigenvalues of the symmetric ball matrix A_Δᵀ A_Δ − A_cᵀ A_c by verifyeigall on that HermitianBallMatrix (Rump and Lange 2023), all of whose lower ends must be nonnegative.

Reference

J. Horáček, Interval linear and nonlinear systems, doctoral thesis, Charles University, Department of Applied Mathematics, Prague, 2019 ([26]), Theorem 11.13.

BallArithmetic.det_hadamard — Function
det_hadamard(A::BallMatrix) -> DeterminantResult

Section 8.4.3 of Horáček (2019): by Hadamard's inequality, for every matrix of the interval matrix A,

|det(A)| ≤ d = ∏_i ( Σ_j mag(A_ji)² )^(1/2),

the product of the largest Euclidean norms of the columns. The same holds with the rows, and the smaller of the two bounds is returned, as the ball of centre zero and radius d. The sign of the determinant cannot be detected in this way. Real or complex input.

source
BallArithmetic.det_gershgorin — Function
det_gershgorin(A::BallMatrix) -> DeterminantResult

Section 8.4.2 of Horáček (2019), for a real interval matrix. Every eigenvalue of every matrix of A lies in an interval Gerschgorin disc, of centre mid(A_ii) and radius rad(A_ii) + Σ_{j≠i} mag(A_ij), and a group of k discs whose union is connected (a "bunch") contains k eigenvalues. With [a, b] the projection of a bunch on the real axis, the product of its k eigenvalues lies in the interval of Figures 8.3 and 8.4 of the thesis:

  • [a, b] for one disc;
  • [a^k, b^k] when a > 0; when b < 0, [a^k, b^k] for odd k and [b^k, a^k] for even k;
  • when a ≤ 0 ≤ b and |a| ≤ |b|, [a b^(k−1), b^k];
  • when a ≤ 0 ≤ b and |a| > |b|, [a^(k−1) b, a^k] for even k and [a^k, a^(k−1) b] for odd k.

Complex eigenvalues come in conjugate pairs and the product of a pair, the square of its modulus, lies between the squares of the smallest and the largest modulus of [a, b] (Figure 8.5), so the same intervals hold. The determinant is enclosed by the product of the intervals of the bunches. The ends of the discs and the powers are rounded outwards.

The thesis remarks that the overestimation may be large, and that the method suits tight intervals or a matrix close to a diagonal one. Throws on complex input, where the discs are not centred on the real axis.

source
BallArithmetic.det_cramer — Function
det_cramer(A::BallMatrix) -> DeterminantResult

Section 8.4.4 of Horáček (2019). By Cramer's rule the first coefficient of the solution of A x = e₁ is x₁ = det(A_{2:n})/det(A), with A_{2:n} the matrix without its first row and column, so that (8.3)

det(A) ⊆ det(A_{2:n}) / x₁

for an enclosure x₁ of that coefficient over the interval matrix. The rule is applied recursively down to order one. The enclosure of x₁ is that of verifylss. The method works when no enclosure of x₁ in the recursion contains zero and every solve is certified; otherwise the returned ball has radius Inf.
